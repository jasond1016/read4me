# 留声绘本 Read4Me

一款本地优先的 Android 绘本陪读原型。父母正常朗读一次，应用持续保存真实声音，并在翻页后记录新书面的照片和时间点。

## 当前范围（P0 + P1 + P2）

- 家庭绘本架
- 陪读前设备与书面校准
- 单文件连续 AAC 录音
- 首个书面拍摄
- 手动翻页标记
- 基于帧运动、重新稳定及内容变化的自动翻页标记
- 每个书面的参考照片和音频时间段
- 录制结果持久化及逐段试听
- 录制时为每个书面保存亮度、对比度归一化视觉指纹
- 儿童阅读模式自动识别家庭书库中的绘本和书面
- 连续多帧确认、最低相似度和候选差距保护，低置信度时不播放
- 自动播放当前书面的父母录音，读完原地等待
- 拖动时间轴编辑相邻书面的共享音频边界
- 合并误切分的相邻书面
- 单独重录任意书面，不重新编码或覆盖整本书的原始录音
- 所有数据仅保存在 Android 应用私有目录

暂未包含 OCR、ASR、声音克隆、波形级音频编辑和绘本包导出；这些属于后续阶段。

## 构建环境

- Android Studio / JDK 17+
- Android SDK 35
- 最低 Android 8.0（API 26）

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat testDebugUnitTest assembleDebug
```

调试 APK 输出到：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 真机试用

1. 将 Android 手机或平板固定，后置摄像头垂直朝向桌面。
2. 安装调试 APK，并授予摄像头和麦克风权限。
3. 点击“录一本新书”；拍封面时选“单页／封面”，拍内容时选“左右两页”，让文字顶部对准取景框箭头。
4. 点击“开始陪读”，正常朗读并翻页。首个书面保存后会默认切换到“左右两页”，需要时仍可随时改回单页。
5. 如果自动检测漏掉一次翻页，点击“标记翻页”。
6. 完成后逐个试听书面，确认自动切分是否自然。
7. 拖动时间轴调整书面之间的共享音频边界，或合并、单独重录。
8. 返回书架并打开孩子阅读模式，将任意已录书面放入取景框。

自动翻页和视觉匹配阈值目前是通用初始值，需要用不同尺寸、纸张和光线条件下的真实绘本继续校准。0.3 版统一了录制与儿童模式的实际相机区域，并加入小幅位置偏移容错、前后书面优先级以及详细识别诊断。此前版本的旧视觉指纹会在复核页标记为“旧版指纹”，需要重新录制后才能用于新版自动阅读模式。
