# 留声绘本 Read4Me

一款本地优先的 Android 绘本陪读原型。父母正常朗读一次，应用持续保存真实声音，并在翻页后记录新书面的照片和时间点。

## 当前功能（2.1）

- 家庭绘本架
- 陪读前设备与书面校准
- 连续 AAC 录音；暂停后保存，续录追加独立音频片段
- 首个书面拍摄
- 手动翻页标记
- 基于帧运动、重新稳定及内容变化的自动翻页标记
- 每个书面的参考照片和音频时间段
- 录制结果持久化及逐段试听
- 录制时为每个书面保存亮度、对比度归一化视觉指纹
- 儿童阅读模式自动识别家庭书库中的绘本和书面
- 连续多帧确认、最低相似度和候选差距保护，低置信度时不播放
- 自动播放当前书面的父母录音，读完原地等待
- 拖动时间轴编辑相邻书面的共享音频边界
- 合并误切分的相邻书面
- 单独重录任意书面，不重新编码或覆盖整本书的原始录音
- 整本播放、逐页试听、倍速与睡眠定时
- 缺失或不可读取的照片／录音提示及逐页补齐
- 单本绘本 ZIP 导入／分享，整库 ZIP 备份／恢复
- 回收站、识别记录及可重建的波形／缩略图缓存
- 默认保存在 Android 应用私有目录；用户可以主动导出备份

暂未包含 OCR、ASR、声音克隆和自动云同步。编辑通过音频片段和时间边界完成，不改写原始音频波形。

## 保存与恢复

- 整本录制切到后台时停止当前录音并尝试保存；回到应用后由用户继续录制。
- 单页重录切到后台后暂停，回到页面可确认保存或取消；保存失败可以重试。
- 系统重建页面时，按绘本与书面 ID 重新读取已保存内容，恢复编辑位置和补拍／补录入口。播放器不会因恢复页面而自动开始播放。
- 返回逐页列表时保留筛选与滚动位置。
- 恢复以已经写入磁盘的内容为准：突然断电、进程被直接终止时尚未封装的录音，以及未确认的整理草稿，不保证恢复。
- 媒体检查包括小尺寸图片解码、音频轨道／时长与片段范围；不等同于逐采样验证整个媒体文件。

## 备份

书架中的单本分享操作导出该书的 ZIP 包；可通过导入绘本恢复。进入“管理”可以导出或恢复整库 ZIP。导入会创建新的绘本 ID，不覆盖已有绘本。回收站内容不包含在整库备份中；仍需保留的书请先恢复到书架。

## 构建环境

- Android Studio / JDK 17+
- Android SDK 35
- 最低 Android 8.0（API 26）

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat testDebugUnitTest assembleDebug lintDebug
```

调试 APK 输出到：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 真机试用

1. 将 Android 手机或平板固定，后置摄像头垂直朝向桌面。
2. 安装调试 APK，并授予摄像头和麦克风权限。
3. 点击“录一本新书”；拍封面时选“单页／封面”，拍内容时选“左右两页”，让文字顶部对准取景框箭头。
4. 点击“开始陪读”，正常朗读并翻页。首个书面保存后会默认切换到“左右两页”，需要时仍可随时改回单页。
5. 如果自动检测漏掉一次翻页，点击“标记翻页”。
6. 完成后逐个试听书面，确认自动切分是否自然。
7. 拖动时间轴调整书面之间的共享音频边界，或合并、单独重录。
8. 返回书架并打开孩子阅读模式，将任意已录书面放入取景框。

自动翻页和视觉匹配阈值需要用不同尺寸、纸张和光线条件下的真实绘本继续校准。转动设备或切换单页／双页构图后，自动翻页会等待画面稳定；此时录音继续，仍可手动标记翻页。

详细的真机验证步骤与本次验证边界见 [验证记录](docs/validation.md)。

## 代码组织

- `ui/LibraryScreen.kt`、`SetupScreen.kt`：书架、管理和录制准备。
- `ui/RecordingScreen.kt`、`RecordingComponents.kt`、`RecordingCaptureState.kt`：录制流程、布局和相机稳定状态。
- `ui/ChildReadingScreen.kt`：儿童翻页识别与播放。
- `ui/ReferenceCaptureScreens.kt`、`RerecordScreen.kt`：补拍、参考照片验证、插页与补录。
- `ui/CaptureComponents.kt`、`CaptureGeometry.kt`、`StoryMedia.kt`：共享拍摄布局、几何规则与媒体展示。
- `NavigationState.kt`：只保存稳定 ID 的导航恢复。
- `model/BookReadiness.kt`、`model/MediaProbe.kt`、`data/AndroidMediaProbe.kt`：媒体可用性及缓存。
